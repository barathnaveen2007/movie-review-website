About Movie Review

Welcome to Movie Review, a movie search website where users can search for movies and view detailed information such as posters, ratings, release dates, genres, and overviews.

Purpose

The purpose of this website is to help users quickly find information about their favorite movies using data from TMDB (The Movie Database).

Technologies Used

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express.js
  • SQLite
  • TMDB API
